# UniVerse — AURAK Student Community

A working front-end prototype of UniVerse: a community platform for AURAK students,
with a campus feed, events, a student business marketplace, Rate My Professor,
premium chat channels, and UniVerse Perks.

This is a client-side demo (vanilla HTML/CSS/JS, state kept in localStorage) —
there is no real backend, payment processing, or AI moderation service behind it.
Live site: see the GitHub Pages URL in the repo settings.
